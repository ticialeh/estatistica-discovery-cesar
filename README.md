# 📊 Discovery: O que a Estatística tem a ver comigo?

> **Atividade 1 - Disciplina de Estatística**  
> *Projeto desenvolvido para o programa Embarque Digital (CESAR School).*

---

## 📌 Sobre o Projeto

Este projeto consiste em uma página web interativa criada com **HTML5** e **CSS3**, desenvolvida para apresentar os conceitos fundamentais da Estatística, sua evolução histórica e suas aplicações práticas. 

A apresentação foi estruturada com o auxílio de **LLMs (Large Language Models)**, utilizando **Gemini** e **ChatGPT** como parceiros de estudo e geração de código.

## 🧬 Conexão Interdisciplinar: Bioinformática

O principal diferencial da apresentação é abordar a **Bioinformática** como a área de convergência entre os dois cursos:

* **Sistemas & Programação (ADS):** Desenvolvimento de algoritmos para processamento e análise de grandes volumes de dados.
* **Ciências Biológicas (Biomedicina):** Compreensão do contexto genômico, epidemiológico e molecular.
* **Estatística:** A linguagem central que valida padrões, modelos preditivos e sequenciamentos genéticos.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação dos dados em formato de cards e tópicos.
* **CSS3:** Design responsivo, paleta visual inspirada na identidade do CESAR School e gradientes sem dependência de imagens externas.
* **LLMs:** Gemini & ChatGPT para suporte na sintetização do conteúdo e otimização do código.
